## 安装

1. 将插件 DLL 放入 `ServerPlugins` 文件夹
2. 启动服务器，插件会自动创建配置目录 `tshock/黑市/`
3. 编辑生成的 JSON 配置文件
4. 执行 `/reload` 或重启服务器加载配置

---

## 配置文件

所有配置文件位于 `tshock/黑市/` 目录下。

### 黑市.json

商店核心配置，包含商品列表、兑换规则、显示设置。

```json
{
  "购买浮动文本": true,
  "购买聊天栏文本": false,
  "兑换浮动文本": true,
  "兑换聊天栏文本": false,
  "每页显示行数": 10,
  "显示列数": 1,
  "兑换规则": [
    {
      "来源物品ID": 74,
      "来源物品名称": "铂金币",
      "目标货币": "元宝",
      "兑换比例（1个来源物品换多少目标货币）": 1
    }
  ],
  "商品模板": {
    "货币": "元宝",
    "价格": 1,
    "数量": 1,
    "前缀": 0,
    "进度": [],
    "职业": [],
    "指令": [],
    "盲盒": [],
    "冷却": 0
  },
  "商品列表": [
    {
      "名称": "生命水晶",
      "价格": 10,
      "物品": 29,
      "进度": ["肉山"]
    },
    {
      "名称": "墓碑*7",
      "价格": 10,
      "物品": 1175,
      "数量": 7
    }
  ]
}
```

#### 字段说明

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `购买浮动文本` | bool | true | 购买时在玩家头顶显示浮动文字 |
| `购买聊天栏文本` | bool | false | 购买时在聊天栏发送消息 |
| `兑换浮动文本` | bool | true | 兑换时在玩家头顶显示浮动文字 |
| `兑换聊天栏文本` | bool | false | 兑换时在聊天栏发送消息 |
| `每页显示行数` | int | 10 | 商品列表每页显示的行数 |
| `显示列数` | int | 1 | 商品列表每行显示的列数（1-3） |

#### 商品模板

商品模板定义了商品的默认属性，商品列表中的商品可以**覆盖**模板中的任意字段。

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `货币` | string | "元宝" | 默认货币名称 |
| `价格` | int | 1 | 默认价格 |
| `数量` | int | 1 | 默认购买数量 |
| `前缀` | int | 0 | 默认物品前缀ID |
| `进度` | string[] | [] | 默认进度条件（满足其一即可） |
| `职业` | string[] | [] | 默认允许购买的职业 |
| `指令` | string[] | [] | 购买后执行的TShock指令，`{0}`替换为玩家名 |
| `盲盒` | object[] | [] | 盲盒奖励列表 |
| `冷却` | int | 0 | 购买冷却时间（秒），0表示无冷却 |

#### 商品列表字段

商品列表中的每个商品可以只填写需要**覆盖模板**的字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| `名称` | 是 | 商品显示名称 |
| `物品` | 是 | 物品ID |
| `价格` | 否 | 覆盖模板价格，0表示使用模板 |
| `数量` | 否 | 覆盖模板数量，0表示使用模板 |
| `货币` | 否 | 覆盖模板货币，空表示使用模板 |
| `前缀` | 否 | 覆盖模板前缀，null表示使用模板 |
| `进度` | 否 | 覆盖模板进度，null表示使用模板 |
| `职业` | 否 | 覆盖模板职业，null表示使用模板 |
| `指令` | 否 | 覆盖模板指令，null表示使用模板 |
| `盲盒` | 否 | 覆盖模板盲盒，null表示使用模板 |
| `冷却` | 否 | 覆盖模板冷却，0表示使用模板 |

#### 盲盒奖励

```json
"盲盒": [
  {
    "物品": 29,
    "数量": 1,
    "权重": 10
  },
  {
    "物品": 129,
    "数量": 1,
    "权重": 1
  }
]
```

按权重随机抽取一个奖励。总权重 = 10 + 1 = 11，第一个奖励概率 10/11，第二个 1/11。

#### 兑换规则

```json
{
  "来源物品ID": 74,
  "来源物品名称": "铂金币",
  "目标货币": "元宝",
  "兑换比例（1个来源物品换多少目标货币）": 1
}
```

玩家手持物品执行 `/兑换 [数量]`，即可将手持物品兑换为目标货币。

#### 字段说明

| `进度条件` | string | 接取任务所需的世界进度（空表示无限制） |
| `允许职业` | string[] | 允许接取的职业（空表示所有职业） |
| `货币奖励` | object[] | 完成奖励 |
| `执行指令` | string[] | 完成时执行的指令 |

#### 任务状态流转

```
未接取 → /接取 → 进行中 → 击杀达标 → 已完成 → /提交 → 已提交
            ↓                              ↓
          /放弃 ←────────────────────── 放弃
```

```json
{
  "击杀浮动文本": true,
  "击杀聊天栏文本": true,
  "掉落规则": [
    {
      "NPCID": 4,
      "货币名称": "功勋",
      "掉落数量": 10
    },
    {
      "NPCID": 1,
      "货币名称": "声望",
      "掉落数量": 3
    }
  ]
}
```

#### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `击杀浮动文本` | bool | 击杀时在玩家头顶显示掉落信息 |
| `击杀聊天栏文本` | bool | 击杀时在聊天栏显示掉落信息（仅掉落≥5或Boss时） |
| `NPCID` | int | 怪物ID |
| `货币名称` | string | 掉落的货币名称 |
| `掉落数量` | int | 每次击杀掉落的数量 |

> 掉落会平分给所有对怪物造成过伤害的玩家。

## 数据库

使用 SQLite 数据库 `tshock/黑市/黑市.sqlite`，包含以下表：

| 表名 | 说明 |
|------|------|
| `黑市货币` | 玩家各货币余额 |
| `黑市冷却` | 商品购买冷却时间 |
| `黑市职业` | 玩家当前职业 |
| `黑市任务` | 玩家任务状态与进度 |

## 配置详解

### 商品系统

商品支持以下高级特性：

**进度限制** - 只有世界进度满足条件才能购买：
```json
"进度": ["肉山", "花后"]
```
满足任一条件即可购买。

**职业限制** - 只有指定职业能购买：
```json
"职业": ["战士", "法师"]
```

**执行指令** - 购买后自动执行TShock指令：
```json
"指令": ["buff {0} 1 3600", "heal {0}"]
```
`{0}` 会被替换为购买者玩家名。

**盲盒** - 购买后随机获得一种奖励：
```json
"盲盒": [
  {"物品": 29, "数量": 5, "权重": 10},
  {"物品": 129, "数量": 1, "权重": 1}
]
```

**冷却** - 购买后进入冷却：
```json
"冷却": 3600
```
单位秒，每个玩家独立计算。

---

### 兑换系统

手持要兑换的物品，执行 `/兑换 [数量]`。

- 不填数量默认兑换1个
- 填 `all` 或数量大于手持数量则兑换全部

---

### 职业系统

- 玩家初始为 `默认职业名称`
- 只有 `可转职: true` 的职业才能转走
- 转职后无法再次更改（除非管理员重置）
- 转职时自动发放奖励物品和执行指令
- 职业颜色会显示在聊天前缀中

---

### 任务系统

任务类型目前仅支持**击杀指定NPC**。

任务进度自动追踪，击杀达标后状态变为"已完成"，玩家需手动 `/提交` 领取奖励。

**接取限制**：
- 不能重复接取同一任务
- 不能超过 `最大接取数量`
- 需满足 `进度条件` 和 `允许职业` 限制

---

### NPC掉落系统

基于伤害记录分配：
- 只有对NPC造成过伤害的玩家才能获得掉落
- 多个玩家参与则各自获得完整掉落数量（不分割）

---

## 进度条件

进度条件支持逻辑运算符：

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `&` | 与（AND） | `肉山&花后` |
| `\|` | 或（OR） | `克眼\|克脑` |
| `!` | 非（NOT） | `!肉山` |

可以使用中文别名或直接写英文字段名。

---

## 聊天前缀

安装插件后，玩家聊天会自动添加职业前缀：

```
[战士] 玩家名: 聊天内容
```

前缀颜色由职业配置的 `颜色` 字段决定。

## 错误排查

### 配置重载报错不显示

确保使用最新版本，旧版本子系统错误仅写入日志文件。新版会在聊天栏统一显示所有配置错误。

### JSON格式错误

所有配置都有严格的JSON格式验证，错误时会：
1. 在日志文件记录详细错误信息
2. 在聊天栏显示错误摘要
3. 使用默认空配置继续运行

常见错误：
- 多余的逗号
- 缺少引号
- 中文字段名写错

### 数据库锁定

SQLite 使用文件级锁，如果服务器崩溃可能导致数据库锁定。删除 `黑市.sqlite` 可重置（会丢失所有数据）。
